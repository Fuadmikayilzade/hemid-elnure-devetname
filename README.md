# 💍 Zülfüqar & Aylin — Toy Dəvətnaməsi

## Vercel-ə deploy etmək üçün:

### 1. Fayl hazırlığı
Aşağıdakı faylları `public/` qovluğuna əlavə edin:
- `music.mp3` — öz musiqi faylınız (bu adda saxlayın)
- Şəkillər artıq yerindədir (img1–img5)

### 2. Vercel-ə import
1. [vercel.com](https://vercel.com) saytına daxil olun
2. "New Project" → GitHub repo-nuzu seçin (bu qovluğu push edin)
3. Framework: **Create React App** (avtomatik aşkarlayacaq)
4. "Deploy" düyməsinə basın

### 3. Xüsusiyyətlər
- 📧 Məktub açılması animasiyası
- ☀️🌙 Gündüz/gecə rejimi keçidi
- ⏱ Canlı geri sayım sayğacı
- 🤍 Toxunanda açılan cütlük şəkli
- 👗 Dress code bölməsi (rəng palitrası ilə)
- 📋 İştirak blankı → WhatsApp göndərmə
- 📸 Google Photos albom linki
- 🗺 Google Maps / Bolt / Yango / Waze naviqasiya
- 🎵 Fon musiqisi

### Qeyd
`music.mp3` faylını `public/` qovluğuna əlavə etməyi unutmayın!
